# CPGS Tours & Travel Website

This is a dependency-free static website starter for CPGS Tours & Travel.

## Open

Open `index.html` in a browser.

## Files

- `index.html` - page structure and content
- `styles.css` - responsive visual design
- `script.js` - mobile navigation and inquiry form interaction
